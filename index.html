❓ FAQ 常见问题

「额度口径」「额度倍率」分别是什么？
额度口径 = 平台怎么计费：Claude 按「5 小时滚动会话 + 每周上限」、Cursor 按模型用量金额、Copilot 按 Premium Requests / AI Credits、国内多为积分 / Token 配额。额度倍率 = 把额度折算成钱再除以月价（awesome-coding-plan 的方法论），倍率越高名义性价比越高；但 MiniMax 月倍率 88.65× 最高、其 5h 周期倍率却一般——请按自己的使用节奏对号入座。
Token 实时价格榜的数据从哪来？会不会是假的？
浏览器直接从 models.dev/api.json 拉取（GitHub 开源项目 sst/models.dev，社区持续提交、CDN 分发，返回体带 CORS 全开放头）。拉取成功时页面显示绿色圆点和拉取时间；网络失败时自动降级到内置快照（黄色圆点，快照日期 2026-09-13），绝不伪造"实时"假象。
价格会变吗？以哪个页面为准？
会。AI 订阅价格与额度调整非常频繁（如 GLM 2026 年内就经历了次数制 → 积分制整体改版）。本站价格仅供决策参考，付款前请务必以平台官网为准；每个卡片底部附有来源链接与采集日期。
数据多久更新一次？怎么保证真实性？
① 每天 09:00（北京时间）GitHub Actions 自动巡检：重生成 models.dev 兜底快照、对官方定价页做内容哈希变动检测、抓取官方 changelog / 状态页与公开社区订阅源、对比价格库与 OpenRouter 免费模型清单；② 官方页或价格库有变动，自动挂「待核实」并开 issue，人工核价后才改表；③ 模型 API 价格每次打开页面实时拉取 models.dev（缓存 24 小时）；④ 来源分级：官方直采（绿标）> 实时数据源（青标）> 聚合参考（蓝标）> 社区情报（黄标，仅作线索）。每个源的抓取成败都公开在「市场动态 → 信息源健康」，连续失败会标注为已失效——不做假巡检。
按量计费和订阅到底怎么选？
用上面的 Token 实时价格榜估算：轻度用户（每月折算 API 费 < $10）选按量计费更便宜，如 DeepSeek V4 Flash（输出 $0.6/M）；中重度用户（每天数小时 Agent）订阅几乎必赢——Claude Pro 倍率 63.6× 意味着同等 API 用量要花 $1,272。处于中间地带就选 $10–20 档订阅 + 超出按量的混合模式（Cursor / Copilot 均支持）。
本站有推广链接吗？
没有。站内所有外链均为官方页面、官方文档或开源项目（GitHub 等），不含任何 referral / 返佣参数，推荐结论不受商业利益影响。

🗓️

更新频率

  • 每天 09:00：GitHub Actions 自动巡检——重生成 models.dev 兜底快照、对官方定价页做哈希变动检测、抓取官方 changelog / 状态页 / 社区订阅源、对比价格库与免费模型清单
  • 官方页有变动：自动挂「待核实」横幅并开 issue，人工核价后才改表
  • 每次打开：Token 价格榜实时拉取 models.dev（本地缓存 24h）
  • 随时：促销、涨价、停售等重大变动，人工确认后录入「市场动态」
🚫

不收录的信息源

  • 逆向 / 公益 / API 中转站（free-one-api、chatanywhere 等）：违反上游 ToS，存在密钥泄露与封号风险，且项目随时消失
  • 共享账号 / 合租：涉及账号安全与平台条款风险
  • 需登录 cookie 抓取的渠道（小红书、即刻、公众号中转）：合规与稳定性均不可接受
  • 对机器人返回验证页的页面：如 OpenAI 定价页实测 403，不假装在监控
🩺

巡检诚实性

  • 每个信息源的抓取成败都记录在 「市场动态 → 信息源健康」，连续 3 天失败会标注为已失效
  • 失败不做静默跳过：早期版本曾因页面改版导致 2 个监控点长期失效而无人知晓，现已修复
  • 抓不到的源就承认抓不到：LINUX DO 与 V2EX 经双环境实测（大陆线路 + GitHub Actions 海外出口）均无法获取——前者 403 Cloudflare、后者空响应，属数据中心 IP 被拦截，自建服务器同样无效，已停用并改为人工巡览
  • JS 渲染的空壳页面（Qoder / CodeBuddy / 火山方舟计费页）明确标注为不可自动监控，不做假巡检
  • 变动需二次确认：页面内容变了不算数，要下一次巡检仍是同一个新值才告警（代价是真实变动晚一天），避免动态渲染页面天天误报
  • 不稳定页面自动停用预警：如 cursor.com/pricing 实测两次抓取正文长度都不同（渲染变体跳变），会被标记为「需人工核对」并停止自动告警
