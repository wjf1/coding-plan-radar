❓ FAQ 常见问题

「额度口径」「额度倍率」分别是什么？
额度口径 = 平台怎么计费：Claude 按「5 小时滚动会话 + 每周上限」、Cursor 按模型用量金额、Copilot 按 Premium Requests / AI Credits、国内多为积分 / Token 配额。额度倍率 = 把额度折算成钱再除以月价（awesome-coding-plan 的方法论），倍率越高名义性价比越高；但 MiniMax 月倍率 88.65× 最高、其 5h 周期倍率却一般——请按自己的使用节奏对号入座。
Token 实时价格榜的数据从哪来？会不会是假的？
浏览器直接从 models.dev/api.json 拉取（GitHub 开源项目 sst/models.dev，社区持续提交、CDN 分发，返回体带 CORS 全开放头）。拉取成功时页面显示绿色圆点和拉取时间；网络失败时自动降级到内置快照（黄色圆点，快照日期 2026-09-13），绝不伪造"实时"假象。
价格会变吗？以哪个页面为准？
会。AI 订阅价格与额度调整非常频繁（如 GLM 2026 年内就经历了次数制 → 积分制整体改版）。本站价格仅供决策参考，付款前请务必以平台官网为准；每个卡片底部附有来源链接与采集日期。
数据多久更新一次？怎么保证真实性？
① 每周一例行核对官方定价页，更新页面顶部日期；② 48 小时内插播促销、涨价、停售等重大变动（线索来自社区每日播报视频、官方公告）；③ 模型 API 价格每次打开页面实时拉取 models.dev（缓存 24 小时）；④ 来源分级：官方直采（绿标）> 聚合参考（蓝标）> 社区情报（仅进动态区）。
按量计费和订阅到底怎么选？
用上面的 Token 实时价格榜估算：轻度用户（每月折算 API 费 < $10）选按量计费更便宜，如 DeepSeek V4 Flash（输出 $0.6/M）；中重度用户（每天数小时 Agent）订阅几乎必赢——Claude Pro 倍率 63.6× 意味着同等 API 用量要花 $1,272。处于中间地带就选 $10–20 档订阅 + 超出按量的混合模式（Cursor / Copilot 均支持）。
本站有推广链接吗？
没有。站内所有外链均为官方页面或开源项目（GitHub / B站 / 新闻），不含任何 referral / 返佣参数，推荐结论不受商业利益影响。
